# Josh's Cookie Creations

Vercel ready Next.js homepage concept for Josh's Cookie Creations.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

## Push to GitHub

1. Create an empty GitHub repository.
2. Open this project folder in Terminal.
3. Run `git init`.
4. Run `git add .`.
5. Run `git commit -m "Initial website"`.
6. Add the GitHub remote shown by GitHub.
7. Run `git push -u origin main`.

## Host on Vercel

1. Sign in at Vercel and choose **Add New Project**.
2. Import the GitHub repository.
3. Keep the detected framework as **Next.js**.
4. Click **Deploy**.

Vercel automatically provides the production URL to the site. For the correct social sharing image URL, add `NEXT_PUBLIC_SITE_URL` in Vercel project settings after the first deployment and set it to the final public URL.
